# /app 공통 디자인·반응형 화면 기반 — 1단계 완료

작성일: 2026-09-16

후속 변경: 같은 날 PC 여행 계획 3단계를 먼저 구현했다. 아래 내용은 1단계 완료 당시 기록이며, 현재 PC 홈·메뉴·여행 저장 범위는 `noplan-pc-trip-workspace-2026-09-16.md`를 따른다.

## 적용 범위

- 기존 430px 고정 phone-frame을 제거하고 화면 전체를 사용하는 app-frame으로 전환했다.
- 1024px 이상: PC 상단 내비게이션, 최대 1200px 콘텐츠 영역, 홈 2열 배치, 탐색·저장 코스 목록 2열.
- 768~1023px: 태블릿 여백과 읽기 너비, 하단 내비게이션, 가운데 대화상자.
- 768px 미만: 한 열 콘텐츠, 터치용 하단 내비게이션, safe-area와 동적 화면 높이 대응.
- 같은 React 화면을 유지하고 CSS로 배치만 변경한다. 화면 너비 분기용 페이지 재마운트나 URL 변경을 사용하지 않는다.
- 로그인·추천 API·PlannerProvider는 기존 구현을 유지한다.

## 공통 디자인

`src/styles/app-layout.css`의 `--np-*` 변수를 공통 기준으로 사용한다.

- 기본 보라색, 선택·hover 색상, 배경·표면·텍스트·테두리 색상.
- 12/18/24px 모서리, 4/8/12/16/24/32px 간격, 공통 그림자·글꼴.
- 기존 추천 화면의 `--nopi-*` 변수와 연결해 중복 팔레트를 줄였다.
- 상·하단 메뉴가 같은 경로 목록과 SVG 아이콘 컴포넌트를 사용한다.
- 키보드 focus 표시, 본문 바로가기, 주요 아이콘 버튼의 44px 터치 영역, reduced-motion 대응.
- 스타일은 `.app-shell`로 범위를 제한한다. 랜딩·인증 전체 화면·관리자 화면의 디자인을 변경하지 않는다.

## 반응형 보완

- 기존 절대 위치의 빠른 추천 화면을 일반 문서 흐름으로 전환해 PC 헤더를 덮지 않게 했다.
- 주소·날짜·시간 입력창의 배경은 전체 화면을 가리고, PC·태블릿에서는 입력창을 가운데 배치한다.
- 코스 지도는 ResizeObserver로 크기 변화를 감지한다. Kakao Maps의 relayout 후 기존 중심 좌표를 유지한다.
- 모바일에서 추천 입력 중에는 기존처럼 하단 메뉴를 숨긴다. PC 상단 메뉴는 유지한다.

## 메뉴와 후속 범위

이번 단계에서는 실제로 연결된 기존 화면을 사용한다.

- PC: 추천받기 / 탐색 / 내 코스 / 마이.
- 모바일: 홈 / 탐색 / 코스 / 마이.

기획된 `찜` 전용 화면과 하단 메뉴 교체는 2단계에서 처리한다. 현재 코스 화면에 '찜'이라는 이름만 붙여 의미를 바꾸지 않았다.

홈 홍보 배너·카테고리·주변 추천의 재구성은 2단계 범위다. 채팅과 버튼 선택형 진입은 유지했고, 홈 시간 선택은 추가하지 않았다.

PC의 여행/날짜/구간 저장과 실시간 협업은 이후 단계다. 이번 변경은 해당 화면들을 담을 공통 레이아웃 기반이다.

## 검증

- 프론트 production build 통과.
- 변경·신규 내비게이션 및 프레임 TypeScript 파일 ESLint 통과.
- MapBoard의 ESLint 진단은 HEAD 원본과 비교하여 기존 9개에서 증가하지 않음을 확인했다. 기존 any 타입·hook 관련 진단은 별도 정리 범위다.
- 브라우저 테스트: 320 / 390 / 768 / 1024 / 1440 / 1920px.
- 상단·하단 메뉴 표시 전환, 문서 가로 넘침, 모바일 입력값 및 동일 DOM 유지 확인.
- 빠른 추천의 선택 상태, 주소 입력값, 열린 날짜 창을 화면 전환 중 유지하는지 확인.
- 자유 입력 → 조건 확인, 탐색 목록 → 상세 팝업 → 코스 사용, 장소 상세·교체·마이 화면 확인.
- 지도 컨테이너 크기 변경 시 relayout 증가 및 지도 인스턴스 수 불변 확인.
- API·지도 SDK를 대역으로 사용한 UI 검증이다. 운영 데이터 변경이나 유료 추천 호출을 하지 않았으며 실제 카카오 지도 타일·운영 API 연동은 이번 검증 범위에 포함하지 않는다.

운영 배포와 Git 커밋·푸시는 수행하지 않았다.
