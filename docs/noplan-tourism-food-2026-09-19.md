# 관광공사 음식점 분류 추가

중심 장소 선택창에 음식점(39) 탭을 추가했다. 검색, 사진 카드, 상세 크게 보기, 메뉴/영업시간/휴무/문의/주차/예약/포장 안내, 일정 담기와 저장 검증에 같은 분류를 연결했다. 축제(15)와 숙박(32)은 계속 제외한다. TourAPI의 음식점에는 카페도 포함될 수 있다.

울산은 2026-09-19 공개 API에서 음식점 115곳을 수집했다. 75곳에 사진이 있다. 기존 274곳의 내용과 순서는 그대로 보존했고, 전체는 389곳이다. 지역 목록과 울산·울주 키워드 검색을 합쳐 콘텐츠 ID로 중복 제거하고 울산 주소·구/군·유효 좌표를 확인했다. 운영 DB에 삽입한 것이 아니라 기존 울산 JSON 목록에 추가했다.

음식점은 관광공사 제공 장소이며 Apify 리뷰 기준을 통과한 인증 가게로 취급하지 않는다. 가격을 추정하거나 예산 검증 완료로 표시하지 않는다. 주변 코스 추천 알고리즘은 변경하지 않았다. 방문/검색 통계가 연결되지 않은 검색 결과는 이름순 대체를 안내하며, 기존 자료 없음 표시를 유지한다.

## 배포 파일

- 프론트: `src/api/tourismApi.ts`, `src/features/trips/TourismPicker.tsx`, `tripModel.ts`, `tourismModel.ts`.
- 백엔드: `routes/tourism/service.js`, `details.js`, `ulsan.js`, `routes/trips/validation.js`, `data/tourism/ulsan-tourapi.json`. 백엔드 재시작이 필요하다.
- 수집 스크립트: `node scripts/fetch-ulsan-tourism.cjs --food-only`는 다른 분류를 보존하며 음식점만 다시 수집한다. 옵션 없이 실행하면 여섯 분류를 수집하고, `--expand-types`는 여행코스·쇼핑·음식점을 갱신한다.

음식점 변경은 사용자의 확인용으로 로컬에 반영했으며 운영 배포·커밋·스테이징은 하지 않았다. 프론트와 백엔드를 함께 반영해야 새 분류의 검색과 저장이 동작한다.

## 검증

- 프론트 관광지 일정 모델 4개, 백엔드 관광 검색/상세/울산 정렬 21개와 일정 저장 9개 통과.
- 변경 프론트 파일 ESLint 및 프로덕션 빌드 통과.
- 브라우저에서 전체 389곳, 음식점 115곳, `[백년가게]언양한우불고기` 실제 메뉴/영업시간/휴무일, 60분 담기 확인.
- 미리보기: `http://localhost:5173/dev-preview/ulsan-tourism.html`에서 음식점 탭을 누른다. 샘플 회원은 20대 여성이다.
