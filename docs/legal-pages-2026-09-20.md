| 주소 | 문서 |
| --- | --- |
| `/terms` | 서비스 이용약관 |
| `/privacy` | 개인정보처리방침 |
| `/privacy-consent` | 회원가입 개인정보 수집·이용 동의 |
| `/marketing-consent` | 마케팅 정보 수신 동의 |
| `/privacy/2026-03-23` | 이전 개인정보처리방침 원문 보관 |

로그인하지 않아도 PC·모바일에서 볼 수 있습니다. 회원가입의 동의 항목 내용 보기 및 하단 링크로 연결됩니다. 서버 문서 URL이 없으면 프론트 문서를 미리 볼 수 있지만, 가입 가능 여부나 동의 저장 조건을 우회하지 않습니다. 서버 URL이 있으면 해당 문서가 우선됩니다.

## 배포와 서버 연결

1. `npm run build` 후 `dist` 배포. 위 경로의 직접 접속에도 SPA index.html fallback이 적용되어야 합니다.
2. 사용자 요청으로 공개 화면의 초안·시행 전 안내를 제거했으며, 표시 버전은 `2026-09-20`입니다. 아래 운영 사항의 확인 여부와는 별개인 화면 변경입니다.
3. 백엔드 `.env`에 확정한 문서 주소를 연결하고 기존 PM2 절차로 환경변수를 반영하여 재시작합니다.

```dotenv
SIGNUP_POLICY_VERSION=<확정한 문서 버전>
SIGNUP_TERMS_URL=https://<회원가입 프론트 도메인>/terms
SIGNUP_PRIVACY_URL=https://<회원가입 프론트 도메인>/privacy-consent
SIGNUP_MARKETING_URL=https://<회원가입 프론트 도메인>/marketing-consent
```

`<...>`는 실제 값으로 바꿉니다. `SIGNUP_PRIVACY_URL`은 일반 처리방침 `/privacy`가 아니라 필수 수집·이용 동의문 `/privacy-consent`입니다. 이전 방침의 연락처는 이력 보존을 위해 원문 그대로 남겼습니다.

실제 회원가입 활성화에는 기존 SENS 설정과 회원가입 DB 테이블 등도 필요합니다. 이 프론트 작업에서 운영 서버 환경변수나 DB를 변경하지 않았습니다.

## 운영 확인에 남은 사항

- 휴대폰 인증 요청·전화번호 해시·동의 이력·보안 로그·백업의 실제 보관기간과 탈퇴 시 삭제 절차.
- 실제 사용 중인 호스팅·저장·추천 서비스 등의 위탁 사업자, 위탁 업무, 국외 이전 여부와 관련 상세사항. SENS 발송은 문서에 반영했습니다.
- 만 14세 미만 가입 정책과 실제 가입 처리의 일치 여부.
- 선택 생년월일·성별의 별도 동의 절차. 현재 폼은 선택 입력이며 필수 수집 동의와 별개의 동의 기록은 없습니다.
- 마케팅 발송 전 채널별 수신거부·동의 철회 반영 절차. 현재 한 개의 선택 동의 값만 기록하며 이 작업은 발송 기능을 추가하지 않습니다.

공개 화면의 초안 표시 제거가 미확정 운영 사항의 구현이나 검토 완료를 의미하지 않습니다. 문서를 업데이트할 때 기존 동의자가 확인했던 버전도 보존해야 합니다.
