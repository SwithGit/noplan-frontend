# 모바일 문화·행사 분리 및 코스 주변 행사 — 2026-09-16

## 반영한 동작

- 모바일 하단 메뉴: **문화·행사 / 탐색 / 홈 / 찜 / 마이**. PC 메뉴 구성은 유지.
- 모바일 홈의 문화·전시 추천 바로가기와 빠른 추천·조건 수정·PC 구간 추천의 문화·전시 선택지를 제거.
- 채팅 분류에서도 문화·전시를 코스 목적으로 추론하지 않는다. 문화 관련 요청은 조건 확인 화면에서 문화·행사 탐색 링크를 안내한다.
- 백엔드는 문화 유형과 전시·영화·공연·팝업·미술관/박물관·독립서점·복합문화공간 세부 유형을 새 추천 후보에서 제외한다. 외부 검색 결과의 문화시설 분류도 제외한다. 승인 카탈로그, 타임라인 후보·예비 후보, 기존 생성 경로에 적용했다.
- 기존 DB·저장한 코스·관리자 문화 분류는 보존한다. 저장된 코스의 기존 장소를 삭제하지 않으며, 장소 교체 후보에서는 문화·전시를 제외한다.
- 장소를 교체할 때 원래 슬롯의 방문 날짜를 유지한다.

## 모바일 행사 화면

PC와 동일한 `/app/events` 및 데이터 API를 사용한다. 모바일의 첫 진입은 알고 있는 출발 지역(없으면 서울)과 오늘 날짜가 기본이다. 현 위치 버튼은 사용자가 누른 경우에만 위치를 요청하며, 실패해도 지역을 직접 선택할 수 있다.

지역·방문일은 바로 표시하고 기간·이름·무료 조건은 상세 검색에 둔다. 행사 유형, 정렬, 상세 조회, 기존 여행 담기 기능을 함께 사용한다. 실제 입장 가능 여부와 개최 기간 표시는 구분한다.

## 코스 결과의 주변 행사

- API가 확정한 각 장소의 `scheduledStart` / `scheduledEnd`를 한국 시간의 날짜로 변환한다. 모호한 채팅 문구나 현재 위치를 대신 사용하지 않는다.
- 코스의 각 장소에서 **직선거리 1km 이내**, 그 장소의 방문 날짜와 개최 기간이 겹치는 행사만 조회한다. 좌표·방문 일정이 없는 장소, 종료·취소 행사, 좌표가 없는 행사는 제외한다.
- 가까운 순으로 최대 3개를 코스 결과 아래에 보여준다. 여러 장소와 겹치는 행사는 가장 가까운 일치 장소 번호와 직선거리를 표시한다.
- `주변 행사 더 보기`는 같은 코스 좌표·날짜 조건을 유지한 행사 목록으로 이동한다. 별도의 지역·날짜 검색으로 전환할 수 있다.
- 결과가 없거나 행사 API가 실패하면 추가 영역만 숨기며 코스 결과에는 영향을 주지 않는다. 코스에 행사를 자동 추가하지 않는다.
- 영업·관람 시간, 휴관일, 예매 가능 여부까지 검증한 추천은 아니다. 실제 도보 시간으로 표시하지 않는다.

## API 및 배포

`GET /api/events`에 선택적 `near` 쿼리를 추가했다. 값은 `{lat,lng,index,date,endDate}` 배열을 JSON 문자열로 인코딩하며 최대 15곳이다. 서버가 좌표 범위·날짜·개수·입력 길이를 검증한다. 일치 행사에는 `nearby: {distanceMeters,placeIndex,visitDate}`를 반환한다.

**백엔드와 프론트를 모두 배포한다. 백엔드 먼저 반영하는 것을 권장한다.** 기존 행사 API 키 설정을 그대로 사용하며 새 환경변수·DB 스키마 변경·수동 SQL은 없다. 운영 DB 데이터를 삭제하거나 수정하지 않았다.

## 검증

- 백엔드 전체 테스트 **263개 통과**: 추천 제외·혼합 채팅 목적·기존 목적 입력 처리, 장소별 방문일·거리 매칭, 취소·좌표 없음·기간 불일치 제외, 잘못된 API 입력 검증 포함.
- 프론트 빌드와 변경 파일 ESLint 통과. 기존 500 kB 번들 크기 경고는 남아 있다.
- Edge 브라우저에서 5개 탭 순서, 실제 빠른 추천의 5개 목적 선택지, 지역·날짜·유형 필터, 상세, 빈 결과·오류·재시도 확인.
- 추천 시작→코스 결과→주변 행사→전체 목록 흐름, 일치 행사 없음, 한국 시간 날짜 변환과 잘못된 좌표 제외를 확인.
- 360/390/768/1024/1440px 화면의 가로 넘침 확인. 기존 모바일 홈의 추천·홍보 배너 순서는 유지.
- 흐름 검증은 실제 행사 매칭 서비스를 사용한 모의 API 응답으로 진행했으며 유료 코스 생성 호출이나 운영 계정 저장을 실행하지 않았다. 실제로 수집해 둔 공개 행사 데이터와 공식 포스터로도 화면을 확인했다.
