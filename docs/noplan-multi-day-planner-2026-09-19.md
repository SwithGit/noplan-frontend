# 노피의 코스플래닝: 여행 전체 날짜 편집

- 공통 조건: 목적, 울산 내 지역, 추천 연령·성별. 날짜를 바꿔도 유지되며 다음 추천에 적용한다. 이미 만든 코스를 자동으로 덮어쓰지 않는다.
- 날짜별 조건: 출발·종료 시간과 이동수단. 홈에서 저장한 이동수단을 기본값으로 사용하고 날짜별로 변경할 수 있다.
- 여행 기간의 모든 날짜를 카드로 표시한다. `이 날짜 노피에게 맡기기`는 선택한 날짜만 생성한다.
- 생성 후 조건을 요약해서 접고 기존 지도·장소 편집기를 표시한다. `조건 변경`과 `이날 조건 변경`으로 다시 펼친다.
- 열려 있는 창에서 날짜마다 코스·수정 내용·이동시간을 독립적으로 보관한다. 아직 반영하지 않은 다른 날짜의 장소도 중복 추천에서 제외한다.
- `작성한 일정 반영` / `반영하고 전체 일정 보기`는 수정한 날짜를 모두 검증한 뒤 한 번에 반영한다. 수정하지 않은 날짜는 보존한다. 전체 여행을 채우지 않았어도 작성한 날짜만 반영할 수 있다.
- 반영 전 초안은 창 내부 상태다. 창을 닫을 때 미반영 변경이 있으면 확인하며, 새로고침까지 보존하는 자동 저장은 아니다.
- 공동 편집 중 원본 일정이 바뀌면 기존 workspace의 기준 문서 비교로 덮어쓰기를 차단한다.

검증: `tests/nopiPlanner.test.cjs`의 날짜별 초안·중복 제외·일괄 반영 검증 포함 21개 통과. 프로덕션 빌드 통과. 브라우저에서 울산 2일 여행(첫날 09시 도보 / 둘째 날 10시 차량), 공통 데이트 조건, 각 5곳의 중복 없는 코스 생성, 날짜 왕복 전환, 2일 일괄 반영과 전체 일정 표시를 확인했다.
